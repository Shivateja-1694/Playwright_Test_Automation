Why Playwright?

Basic Features

1. Inbuilt Autowait Capability
2. Inbuilt element checks like visible, stable, receives event, enabled, editable before performing any action
3. Cross Browser compatibility includes all the browsers like Chrome, Safari, Firefox, Microsoft Edge, ... etc.
4. Multi Platform Support like Windows, MacOS, Linux, ... etc.
5. Multilingual Flexibility like Playwright code can be written in Javascript, Typescript, Java, Python, C# (.net)

Advanced Features

1. Tracing and Debugging - Automatic Screenshots, test video recordings, Comprehensive Logging
2. Network Interception - Mock the API Calls to generate own/static data in API Automation
3. Browser Context Management - Save and transfer browser cookies/cache into another/new browser 
4. Codegen Tool - Generate the test code by recording the actions in UI

Here are the steps to fix the issue persistently:
 
1.  **Open PowerShell as Administrator**:
    *   Search for "PowerShell" in the Start menu.
    *   Right-click it.
    *   Select **Run as Administrator**.
 
2.  **Check Current Execution Policy**:
    *   Run this command in PowerShell:
        `Get-ExecutionPolicy -List`
    *   This shows policies for different scopes.
 
3.  **Set Persistent Execution Policy**:
    *   To allow scripts for your user account persistently:
        `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Bypass`
    *   This setting applies only to your user account.
    *   It remains active after you restart your computer.
    *   Answer 'Y' (Yes) if prompted to confirm the change.
 
    *   Alternatively, to allow scripts for all users persistently (requires administrator privileges):
        `Set-ExecutionPolicy -Scope LocalMachine -ExecutionPolicy Bypass`
    *   This setting applies to all users on the computer.
    *   It remains active after restarts.
    *   Answer 'Y' (Yes) if prompted.
    *   Choose the scope (`CurrentUser` or `LocalMachine`) that best fits your needs. `CurrentUser` is often sufficient and safer.
 
4.  **Run Your Command Again**:
    *   Retry your `npm init playwright` command.
    *   It should run without the execution policy error.
 
**Additional Notes**:
 
*   Using `Bypass` lets any script run. Understand the security risk before proceeding.
*   If problems continue, consider reinstalling Node.js. Get the latest version from the Node.js website.

1. What is @playwright/test?

@playwright/test is the Playwright Test package.

When you install Playwright, this package provides things you need to write and run tests, such as:

test → used to define a test
expect → used to verify/assert results
Playwright's test fixtures such as page, browser, etc.

Think of it as:

"Give me the tools provided by Playwright's testing framework."

2. What does require() mean?

require('@playwright/test')

require() is a Node.js function used to import/load something from another module/package.

For example: const calculator = require('./calculator');
means: "Load the calculator module so I can use it in this file."

So: require('@playwright/test')
means: "Load the Playwright Test package so I can use its functionality."
